## 数据读入归一化
不知道 patchtst 模型是怎么处理数据的，先用标准化处理，informer 的关闭了，这样可以统一归一化的方式。

不归一化的话，得到预测数据维度之间的差异会很大，导致使用正式数据集时 mse 特别大。

```python
# src/data/utils.py
from sklearn.preprocessing import StandardScaler
def load_data():
    data = pd.read_csv(DATA_PATH, header=0).values
    scaler = StandardScaler()
    data = scaler.fit_transform(data)  # 归一化数据
    X_train = data[:100]  # 前100步训练
    X_val = data[100:200]  # 后100步验证
    return X_train, X_val
```

## 路径
据我所知，Windows 系统可以使用下面两种路径，而 Linux 系统只能使用第二种路径。

所以为了兼容，最好还是一直使用第二种路径。
```
DIR = "src\\test.txt"
DIR = "src/test.txt"
```

另外，路径最好是相对路径，如果本来就是相对路径，而运行时发现不正常，大概率是因为执行命令的路径不对，最优选是 `cd` 到项目根目录下再执行，次选手动更改代码中的路径。
